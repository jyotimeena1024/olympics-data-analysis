## 🏅 Olympics Data Analysis & ML Predictor

A comprehensive Streamlit web application for analyzing historical Olympics data. This project includes dynamic visualizations and a **Machine Learning model** to predict an athlete's chances of winning a medal.

## 🚀 Live Demo
Streamlit App: https://jyotimeena1024-olympics-data-analysis-app-dlmtmq.streamlit.app/

## ✨ Features
1. **Medal Tally:** View country-wise and year-wise medal tallies.
2. **Overall Analysis:** High-level statistics of the Olympics (events, athletes, countries).
3. **Country-wise Analysis:** Detailed performance of specific countries over time.
4. **Athlete-wise Analysis:** Age, weight, and height distribution of medalists.
5. **🤖 Machine Learning Predictor (NEW):** Uses **Logistic Regression** to predict an athlete's probability of winning a medal based on their Age, Height, Weight, and Sex.

## 🛠️ Tech Stack
- **Python** 
- **Streamlit** (Frontend/UI)
- **Pandas & NumPy** (Data Processing)
- **Plotly, Matplotlib, Seaborn** (Data Visualization)
- **Scikit-Learn** (Machine Learning)

## 📂 Files to know
- `app.py`: Main Streamlit application.
- `helper.py`: Contains all the logic, data processing functions, and the ML model training code.
- `requirements.txt`: List of dependencies required to run the project.
